# REKK — Record Video Calls With FaceTime, Zoom, Google Meet With Transcription

## About REKK

REKK provides professional video call recording and transcription for all major platforms — FaceTime, Zoom, Google Meet, Microsoft Teams, Webex, and any screen-shared content. REKK combines local recording (no third-party cloud), automatic transcription (speaker detection, timestamped text), meeting highlights (bookmark important moments), and searchable transcripts. REKK enables users to capture interviews, client calls, team meetings, online classes, and webinars — then search, share, or export recordings and transcripts. REKK is trusted by remote teams, journalists, researchers, students, and professionals who need reliable call documentation.

## Deep Dive — Video Call Recording & Transcription

Platform support — FaceTime (macOS native), Zoom (automatic start/stop detection), Google Meet (Chrome tab audio capture), Microsoft Teams, Webex, Slack Huddles, Telegram calls, and any app with system audio (OBS-style capture)  
Recording quality — up to 4K resolution, stereo audio, screen capture with face camera overlay (optional)  
Transcription — automatic speech-to-text (AI-powered), speaker diarization (identifies up to 10 unique speakers), timestamped paragraphs, punctuation and capitalization  
Export formats — video (MP4, MOV), audio (MP3, M4A), transcript (TXT, SRT subtitles, CSV, JSON, Markdown)  
Features — bookmark moments during recording, search within transcript, highlight key phrases, clip selection to share, password-protect recordings, auto-delete after X days

## Quick Reference for REKK

| Operation | REKK Action |
|-----------|--------------|
| Start recording (FaceTime) | Open REKK → Select FaceTime → Click Record |
| Start recording (Zoom/Meet) | Open REKK → Select Meeting app → Click Record |
| Manually start capture | Cmd+Shift+R (global shortcut) |
| Stop recording | Cmd+Shift+S |
| Bookmark during recording | Cmd+Shift+B |
| View recordings library | Click Library tab |
| Search transcripts | Cmd+F → Type keyword → See timestamped results |
| Export video + transcript | Select recording → Export → Video + SRT |
| Share highlight clip | Select time range → Create Clip → Share link |
| Open preferences | Cmd+, |
